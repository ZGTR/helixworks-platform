# Course map

Each course day points to tested files in this repository and an immutable course
tag. The platform course builds the system; the authorization course attacks and
narrows its authority.

## Building HelixWorks: 10 days

1. Product request path and repository contract
2. MVC, SRP, DRY, IoC/DI, ports and composition roots
3. Tenant/project/blueprint control plane
4. Bounded run orchestration
5. Artifact and preview boundary
6. Outbox, PubSub, idempotency and compensation
7. Governed connector adapters
8. Tests, resilience and OpenTelemetry evidence
9. Local-to-production ECS infrastructure as code
10. Immutable promotion, failed canary, rollback and retirement

## Securing HelixWorks: 12 days

1. Owners, immutable versions and trust planes
2. Application knowledge versus platform authority
3. Connector credentials and workload identity
4. Identities and effective authority
5. Enterprise login, teams, OAuth 2.0 and OIDC
6. Run authorization and attenuated capabilities
7. Exact MCP tool and argument authorization
8. Delegated and managed MCP access
9. Human approval and nested-agent delegation
10. Network trust, infrastructure and delivery enforcement
11. Revocation convergence, audit and observability
12. Threat-model tests, canary, rollback and retirement
